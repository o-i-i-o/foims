第三层：能力跃迁（较大投入，需安全设计）
SNMP SET 写操作：端口启用/禁用（ifAdminStatus）、描述写入（ifAlias）——从"观测"走向"处置"；必须走三权分立鉴权 + 审计日志 + 二次确认，且仅 v2c/v3 写视图分离
SNMP 自动发现纳管：给定网段批量 GetBulk sysDescr/sysName，找出"响应 SNMP 但未登记 CMDB"的设备，一键生成设备草稿（与判活、未登记设备检测共用扫段框架）
MIB 浏览器（管理员诊断工具）：任意 OID get/walk 的调试端点 + 前端页，排障利器；权限沿用实时探测的管理员守卫，建议限定只读 OID 白名单前缀
轮询分级调度：核心设备短周期、接入设备长周期（当前全局 5 分钟写死 cron），按设备/分组配置 interval，并允许单独关闭某设备的轮询
路由/邻居表采集（ipCidrRouteTable、v1 路由协议表）：面向三层设备的路由摘要展示——建议评估真实需求后再排期，优先级低于以上各项
