## CSS 清理与重组方案

目标：清理重复/冲突样式、删除死代码、修复选择器泄漏与加载机制，并把错放在 `components/` 下的页面/模态框专用文件归位。**所有 `css/components/` 下的通用组件文件（buttons/cards/forms/modals/tables/badges/toasts/toggles）保持不动。**

---

### A. 移动 3 个错放的文件（保留文件名，仅改目录）

| 原路径 (components/) | 新路径 | 实际用途 |
|---|---|---|
| `network-config.css` | `css/modals/network-config.css` | 仅 room-modal.html + room.js 使用 |
| `network-card-manager.css` | `css/modals/network-card-manager.css` | 仅 networkCardManager.js / device.js（设备模态框）使用 |
| `network-usage.css` | `css/pages/network-usage.css` | 仅 networks.js（网络页面）使用 |

- 用 `git mv` 移动，保留历史。
- 更新 `main.html:24-26` 三条 `<link>` 的路径（`components/` → `modals/` 或 `pages/`）。

---

### B. 删除纯重复规则

1. **`modals/unified-device-ports.css`**：删除 `.modal + .modal` 与 `.modal + .modal .modal-content`（135-142 行）——与 `components/modals.css:270-277` 完全重复。
2. **`pages/visualization.css`**：
   - 删除死代码块 `.port-groups-container / .port-group / .port-group h4 / .port-grid`（188-217 行）——核查确认这些类只由 devicePorts/unifiedDevicePorts 模态框 JS 产生，可视化 JS 不产生。
   - 删除重复的 `.port-tooltip` 基础样式（250-266）与 `.port-tooltip::after`（273-282）——与 unified-device-ports.css 重复；保留 `.viz-port-item:hover .port-tooltip`（268-271）触发规则。

---

### C. 删除死代码

3. **`modals/unified-device-ports.css`**：删除 `.modal-xl`（3-6 行及其在 220-222 的响应式分支）——全仓库无任何 html/js 引用。
4. **`modals/network-card-manager.css`**（移动后）：删除整段 `.nc-outlet-*` outlet-picker（约 166-251 行，~85 行）——全仓库无任何引用。

---

### D. 修复选择器冲突（全局泄漏）

5. **`pages/dashboard.css`**：从 `@media 768px` 块中删除无作用域的 `.stat-value`、`.stat-icon`（183-189 行）——它们覆盖了 `cards.css` 的同名通用类，且与 responsive.css 重复。
6. **`responsive.css`**：将 110、316 行的 `.stat-value` 收窄为 `.stat-card .stat-value`；并在 768px 块补一条 `.stat-card .stat-icon { font-size: 2rem }` 以保留原移动端表现。行为不变，杜绝全局泄漏（networks.js 的 `.stat-value` 在 `.usage-stats` 作用域内，不受影响）。
7. **`modals/unified-device-ports.css`**：将 `.empty-message / .error-message`（144-155 行）限定到端口模态框容器（如 `.port-groups-container`），停止对 `forms.css` 全局 `.error-message` 的覆盖。

---

### E. 修复加载机制

8. **`js/utils/styleLoader.js`**：`dashboard.css` 与 `organization.css` 已在 `main.html` 静态引入，`PAGE_STYLES` 里重复加载（且 loadedStyles 未登记静态 link 导致重复 append）。移除这两个条目，只保留动态加载的 `visualization.css`：
   ```js
   const PAGE_STYLES = {
     resources: ['/static/css/pages/visualization.css'],
     visualization: ['/static/css/pages/visualization.css']
   };
   ```
9. **空的 `css/main.css`**：删除文件，并移除 `index.html:9`、`init_index.html:9` 对它的 `<link>`（文件仅含 3 行注释，无任何规则）。
