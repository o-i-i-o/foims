# 登录页重构计划（以示例为基础）

## 总体思路
以 `example-files/animatedlogin.html` 作为**新登录页的基础**（替换现有 `index.html`），保留其双栏布局 + 动画角色 + 全套样式和交互 JS。然后做三处适配：

1. **默认用户名登录**（示例原默认邮箱登录）—— 把右面板首个表单的邮箱输入框改成用户名输入框
2. **复用 Google 按钮为「邮箱验证码登录」** —— 第二个按钮（原 "Log in with Google"）改造成邮箱验证码登录：点击切换到邮箱+验证码表单，复用原 `login.js` 的 `handleSendLoginCode` 发送验证码逻辑
3. **补齐原登录页功能** —— 2FA 视图、忘记密码模态框、i18n、记住我，全部从原 `login.js` 接入

## 已确认决策
- 配色：示例原配色（薰衣草左面板、紫 `#5b21b6`/`#6c3ff5`、海军蓝 `#1a1a2e`）
- 字体：系统字体栈（CSP `font-src 'self'` 会拦截 Google Fonts）
- 动画：完整保留示例全部 JS 互动（鼠标追踪、眨眼、密码可见偷看、输入互看、登录失败摇头+难过表情）

## 改动范围（3 个文件）

### 1. `web/static/css/pages/login.css`（重写，自包含）
把示例 `<style>` 块整体迁出，**新增**示例没有但原登录页需要的样式：
- `.login-tabs` / `.tab-btn`（用户名 / 邮箱验证码 切换）—— 用示例的圆角胶囊视觉
- `.login-section`（用户名区 / 邮箱区 切换）、`.form-inline-group`（验证码输入 + 发送按钮并排）
- `.view` / `.view.active`（登录视图 ↔ 2FA 视图切换）+ `.view-header`/`.view-desc`
- `.error-message.show` / `.success-message.show`（接 `login.js` 的 showError）
- **忘记密码模态框自包含样式**：`.modal`/`.modal.active`/`.modal-content`/`.modal-header`/`.close`/`.modal-body`/`.modal-footer`/`.btn-secondary`/`.btn-primary`（修复原页面引用 `.modal` 却没加载 modals.css 的隐患）
- `.sr-only`（无障碍，原页面用到却无样式）
- `@keyframes fadeInUp`、响应式 `@media (max-width: 900px/480px)`
- 作用域隔离：选择器挂在 `.login-body` / `#login-page` / `.login-*` 下，避免污染 `main.html`

### 2. `web/static/index.html`（用示例结构重写 body）
- **保留 head**：CSP、title、`<link>` 引用、i18next 脚本
- **新 body 结构**：`<body class="login-body">` → `#login-page`
  - **左面板**（完全照搬示例）：`.logo`（IPMA logo）、`.characters-wrapper > .characters-scene`（4 个角色，**保留示例所有 id**：`char-purple`/`purple-eyes`/`purple-eye-l/r`/`purple-pupil-l/r` … 供动画 JS）、`.footer-links`
  - **右面板**：`.form-container`（sparkle 图标 + 欢迎语）→
    - `.login-tabs`：`密码认证` / `邮箱认证`（默认密码认证 active）
    - `.login-views`：
      - **`#login-view`**（默认 active）：含 `#login-form`
        - `#password-login-section`（默认 active）：用户名输入框（`id="username"` name="username"）+ 密码框（`id="password"`，带 `.toggle-password` 眼睛切换按钮）+ 忘记密码链接（`#forgot-password-link`）+ 记住我（`#remember-me`）
        - `#email-login-section`：邮箱框（`#email-login-input`）+ 验证码（`#email-login-code` 与 `#send-login-code-btn` 并排，`.form-inline-group`）
        - 提交按钮 `#login-submit-btn`（用示例 `.btn-login` 带 hover 滑动箭头样式）
      - **`#two-factor-view`**：`#two-factor-form` 含 `#two-factor-code`、`#two-factor-submit-btn`、`#back-to-login-btn`（用 `.btn-text-full` 样式）
    - `#login-error`（`.error-message`）
- **忘记密码模态框** `#forgot-password-modal`：自包含结构（`.modal`/`.modal-content`/`.modal-header`/`.close`/`.modal-body`/`.modal-footer`），含 `#forgot-password-form`、`#forgot-email`、`#forgot-password-error`、`#forgot-password-success`
- **i18n**：所有可见文本加 `data-i18n`、`data-i18n-placeholder` 属性（标题/Tab/按钮/placeholder/忘记密码等）
- 引入 `login.js`（module）

### 3. `web/static/js/login.js`（保留核心逻辑 + 接入示例动画）
**核心登录逻辑零改动**，保留：
- `LoginManager` 类、`State`/`LoginMode` 枚举
- `handleSubmit`/`submitPasswordLogin`/`submitEmailLogin`/`handleTwoFactorSubmit`/`handleSendLoginCode`/`handleForgotPassword`/`checkLoginStatus`/`updateFormValidation`/`setLoading`/`startCountdown`/`formatErrorMessage` 等
- 所有 `getElementById` 依赖的 id（新增 password 切换按钮 id 在此文件内取用）

**新增/接线**：
- 把示例的动画模块移植进来：`updateCharacters()`、`calcPosition()`、`calcPupilOffset()`、`scheduleBlinkPurple/Black()`、`schedulePeek()`、鼠标 mousemove 监听、密码框 focus/blur/input 接 `setTyping`/`isPasswordFocused`
- `triggerLoginError()`：登录失败时触发角色摇头 + 难过嘴。**在 `showError()` 内调用**
- `clearError()` 内恢复角色正常姿态
- 密码可见性切换按钮 `.toggle-password` 的事件绑定（示例逻辑：切 type + 换图标 + 触发偷看动画）
- `init()` 末尾初始化动画（启动眨眼定时器、首次 `updateCharacters`）
- 邮箱 Tab 切换：复用原 `handleTabClick`，发送验证码按钮接 `handleSendLoginCode`

## i18n 键规划
新增一个 `login` 命名空间到 `zh.json` / `en.json`（如 `login.title` / `login.subtitle` / `login.password_auth` / `login.email_auth` / `login.username_placeholder` / `login.forgot_password` / `login.remember_me` / `login.sign_in` / `login.two_factor_title` / `login.send_code` / `login.forgot_title` …）。沿用现有 `auth.*` / `two_factor.*` 已有键。`login.js` 内硬编码的中文提示字符串（如 "请输入用户名和密码"）保留不动（与原行为一致），仅 HTML 静态文本走 i18n。

→ **i18n 改动**：仅新增键，不改既有键，避免影响其他页面。

## 不做的事
- 不改后端 API、不改 i18n 已有键、不改 `main.html`、不动其他页面
- 不加载外部字体/资源（遵守 CSP）
- 不删 `example-files/animatedlogin.html`（参考用）
- 不再保留旧 `login.css` 的紫色渐变全屏样式（被示例双栏布局取代）

## 验证方式
1. 启动服务，打开登录页：确认双栏布局、角色动画（鼠标追踪/眨眼）、配色正常
2. 默认显示**用户名 + 密码**登录区；点击「邮箱认证」Tab 切到邮箱 + 验证码区，点「发送验证码」看倒计时
3. 密码框右侧眼睛图标切换明文/密文，明文时紫色角色偷看
4. 错误凭据登录 → 角色摇头 + 难过嘴 + 错误提示
5. 开启 2FA 的账号 → 跳转 2FA 视图，输入验证码登录，返回按钮正常
6. 「忘记密码」→ 模态框打开/提交/成功提示/自动关闭
7. 切换浏览器语言中/英，页面文本切换
8. 缩到 <900px：左面板隐藏、单栏表单；<480px 验证码按钮整行
9. 控制台无 CSP 报错、无 404
