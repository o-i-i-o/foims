# switch_port → device_port 全栈重命名计划

## 决策（已确认）
- **表名/列名**：连数据库表一起改（`switch_ports` → `device_ports`，`source_switch_port_id` → `source_device_port_id` 等），开发库可重建（**不写迁移脚本**，删库重 init）
- **枚举值**：`'switch_port'` → `'device_port'`（cable_links 端点类型 + operation_logs.resource_type），开发库可重建
- **SwitchForSnmp** → `DeviceForSnmp`

## 总览：5 类改动
1. 数据库 DDL（crates/ipma-init/src/schema/）—— 表名/列名/枚举值/触发器/视图/索引
2. 后端 Rust（src/）—— 结构体/函数/路由/SQL 查询/校验常量
3. 前端 JS（web/static/js/）—— API 路径/标识符/枚举字面量
4. 前端 HTML（web/static/modals/）—— `value="..."` 枚举值
5. i18n 键名（zh.json/en.json）+ data-i18n/t() 引用

---

## 1. 数据库 DDL（`crates/ipma-init/src/schema/`）

### `tables/switch_ports.rs` → 重命名文件为 `device_ports.rs`
- `CREATE TABLE IF NOT EXISTS switch_ports` → `device_ports`
- 表内字段不变（port_number/port_name 等）

### `tables/mod.rs`
- `mod switch_ports;` → `mod device_ports;`
- `switch_ports::create(pool)` → `device_ports::create(pool)`

### `tables/topology.rs`
- `source_switch_port_id UUID REFERENCES switch_ports(id)` → `source_device_port_id UUID REFERENCES device_ports(id)`
- `target_switch_port_id` → `target_device_port_id`

### `tables/cable_links.rs`（枚举值 + 表名 + 触发器，最密集）
- 表定义 CHECK：`'switch_port'` → `'device_port'`（a/b_endpoint_type 两处）
- 索引：`idx_switch_ports_device_id ON switch_ports` → `idx_device_ports_device_id ON device_ports`；`idx_switch_ports_port_number` 同理
- 触发器函数 `validate_cable_link_endpoints`：`WHEN 'switch_port'` → `WHEN 'device_port'`，`FROM switch_ports` → `FROM device_ports`（a/b 两处）
- 触发器函数 `prevent_switch_port_deletion_if_linked` → 重命名为 `prevent_device_port_deletion_if_linked`；函数体内 `'switch_port'` → `'device_port'`，错误信息「交换机端口」→「设备端口」
- 触发器：`trg_switch_ports_prevent_delete_linked ON switch_ports` → `trg_device_ports_prevent_delete_linked ON device_ports`（DROP 旧名 + CREATE 新名）
- `find_cable_path` 函数：`FROM switch_ports` / `JOIN switch_ports` / `'switch_port'` 字面量 / `WHEN 'switch_port'` 全部替换

### `tables/indexes.rs`
- `idx_switch_ports_device_id ON switch_ports` → `idx_device_ports_device_id ON device_ports`
- `idx_switch_ports_port_number` 同理

### `tables/views.rs`
- `cable_links_with_details` 视图：`FROM switch_ports` → `FROM device_ports`，`'switch_port'::VARCHAR` → `'device_port'::VARCHAR`

### `tables/triggers.rs`
- `tables_with_updated_at` 数组里 `"switch_ports"` → `"device_ports"`（影响 `trg_{table}_updated_at` 通用触发器）

### `check.rs`（启动健康检查）
- `get_required_tables()` 里 `"switch_ports"` → `"device_ports"`
- `get_table_columns()` 里 `columns.insert("switch_ports", ...)` → `"device_ports"`
